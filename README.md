# Pede Barra

Tudo de Barra do Ribeiro, na tua porta.

App de delivery da cidade de Barra do Ribeiro (RS): restaurantes, farmácias, mercados, entregas Flash e lojas gerais.

## Rodar no computador

```bash
npm install
npm run dev
```

Depois abra http://localhost:3000.

## Onde está cada coisa

- `src/app/` — as telas
- `src/components/` — peças reaproveitadas (logo, botões, cards)
- `src/app/globals.css` — cores e fonte da marca
- `ROADMAP.md`, `CHANGELOG.md`, `IDEIAS.md` — andamento do projeto
